Curso

Carrera



Ingeniería Ambiental



Descripción del proyecto



Este repositorio académico tiene como finalidad organizar, desarrollar y documentar las actividades y avances del proyecto de investigación sobre el desperdicio de alimentos generado en el comedor universitario de la Universidad Peruana Cayetano Heredia.



Objetivo



Investigar cómo se generan y gestionan los restos de alimentos en el comedor universitario, identificando las prácticas actuales, las dificultades y las oportunidades de mejora.
